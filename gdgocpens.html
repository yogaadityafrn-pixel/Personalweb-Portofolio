About The Role

Sebagai bagian dari komunitas global Google Developer Groups (GDG) on Campus di Politeknik Elektronika Negeri Surabaya, saya aktif mendalami dua pilar utama teknologi modern: Machine Learning dan Web Development. Dalam program ini, saya mengasah kemampuan teknis dalam membangun solusi digital yang cerdas dan responsif. Di jalur Machine Learning, saya berfokus pada pengembangan model prediktif dan pemrosesan data, sementara di jalur Web Development, saya mempelajari arsitektur aplikasi web yang skalabel dan berorientasi pada pengalaman pengguna. Melalui ekosistem kolaboratif GDG, saya tidak hanya memperdalam penguasaan tools pengembang Google, tetapi juga belajar mengintegrasikan kecerdasan buatan ke dalam platform berbasis web untuk menciptakan inovasi teknologi yang relevan dengan kebutuhan industri saat ini.

Key Responsibilities

Machine Learning Path

Mempelajari konsep dasar hingga implementasi model supervised dan unsupervised learning, termasuk pengolahan dataset dan evaluasi akurasi model.

Web Development Path

Mengembangkan aplikasi web interaktif dengan fokus pada struktur kode yang bersih (clean code), responsivitas desain, dan integrasi API

Google Technologies

Mendalami pemanfaatan ekosistem pengembang Google (seperti Firebase, TensorFlow, atau Google Cloud) dalam alur kerja pengembangan perangkat lunak.
